# 规范目录页

规范页是组件目录，不是业务屏。做新切片时先打开文件里**已完成的第一份规范页**，抄它的 Header / Section / 卡，不要重发明。

## 建议结构

1. 页标题（或沿用文件 Header：64 标题 + 一句分类说明）
2. 可选 Foundations：色、字、间距标本（已有独立页就不要重复）
3. 组件 Section：一个家族一块（选项 → 组 → 行 → 面板）
4. 参考原稿：产品 UI 溯源，只读

本仓库选择器先例：Section 宽 **2984**、Section 间距 **80**。换文件时以该文件先例为准。

## 卡与组件

- 卡：标题 + 组件集或预览实例 + 状态标签
- 组件：产品画布宽（默认 750），不要拉满目录宽
- 标签格宽 = 对应变体宽；文案 = 变体属性值
- 卡的灰底 / 描边 / 标题不是组件的一部分

## 原稿

- 放在分区末尾或独立「参考原稿」Section
- clone 到规范页时保持只读；真源节点不要改 x/y/文案
- 组件 description 和 `docs/specs` 都写溯源 id
