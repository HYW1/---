# 对照例：申请步骤条（理赔场景，方法可迁移）

这是**练过的一个场景**，用来钉死「变体策略 + 原稿还原 + 别整理过头」。  
换业务时：换文件、文案、溯源 ID。拆法见 [stepper-bar-lessons.md](stepper-bar-lessons.md)，坐标仍以本页为准。

## 矩阵（做对的拆法）

| 组件 | 轴 | 属性 | 溯源 |
|---|---|---|---|
| `步骤条/申请步骤点 AppStepDot` | `状态` 已完成 / 当前 / 未到 | 无（数字由父级画） | `367:6050` / `367:6043` / `367:6047` |
| `步骤条/申请步骤项 AppStepItem` | 同上 | TEXT `标题` `序号`；BOOLEAN `左连线` `右连线` | 点实例 + 标题 |
| `步骤条/申请步骤条 AppStepper` | `状态` 步骤1 / 2 / 3；`查看修改` 有 / 无 | 三步暴露为项实例；连线在间距 + 项 stub | `367:5998` / `367:6179` |

未到点：**60×60** 圆 `#6CA0FF` + 描边 `#1677FF` 4，居中在 **85** 槽。不是 85 的实心圆。

## 点得着

申请步骤条里点「填写就医情况」应选中 **AppStepItem 实例**（菱形）。  
若点到「点槽」Frame：切不了；切 当前/未到 还会把烤死的 2/3 一起换掉。

## 状态与序号解耦

- AppStepDot 当前/未到 内层数字 **opacity 0**
- AppStepItem 上 Absolute TEXT 绑定 `序号`，对齐 85 槽（当前）或 60 圆中心（未到）
- 实例属性：第 1 步 `序号=1`，第 2 步 `2`，第 3 步 `3`
- 切第 2 步 `状态=未到`：仍是「填写就医情况 / 2」，只是点变成 60 环

## 两份原稿的差别（不是同一条）

产品逻辑（用户钉死）：**整条**用 `查看修改` 有 / 无 来切，不要每一步再做一个元件。有的时候：已完成步才出「点击查看/修改」（步骤1 没有已完成步所以没有；步骤2 只有第 1 步；步骤3 第 1、2 步都有）。无的时候整条都没有气泡。三步都做 `状态` 变体，不要让人删步。

| | 无气泡 `367:5998` | 有气泡 `367:6179` |
|---|---|---|
| 用在 | `查看修改=无`（以及步骤1） | `查看修改=有` 且已完成步 |
| 点 y | 21 | 42 |
| 气泡 | 无 | Absolute 在已完成步右侧、连线上方 |

气泡不要做成第 1 列里居中的胶囊，也不要用气泡去撑开列宽。项宽 **HUG** 标题，条上靠 **FILL 间距**铺开。

## 自适应

申请步骤条已经是 `[项][间距 FILL + 连线][项]`。其余条同样：**点固定、项 HUG、条间距 FILL、列表 FILL**。细则见 [adaptive-stepper.md](adaptive-stepper.md)。

## 连线：放进条里的间距 + 项上 stub，不要再做线元件

- 4px 描边 LINE，`SQUARE` cap。已走空白，未到 `#6CA0FF`。
- 间距里一段 FILL；项上左右 stub 接到圆边，**不要穿过圆心**（线不能画在内圆上面）。
- 步骤1 两段都是底色；步骤2 只有 1→2 白；步骤3 两段都白。
- 不要在条根上叠 `进度-*` 矢量，也不要单独做一条「线组件」。

## 目录

- 规范页组件集是全家福。切状态请点**实例**。
- AppStepItem 主组件因 TEXT 默认值共用，当前/未到主组件可能都显示「3」→ 集 `visible=false`，卡上放预览实例（1/2/3）。
- AppStepper 目录展示 **步骤1/2/3 × 查看修改 有/无** 六格（两行三列）。

## 以后不要再犯

1. 看见「乱」先并排截原稿，再决定是穿模还是产品逻辑。
2. 用户说步骤 1/2/3 怎么切、气泡何时出现，按原话做两轴，不要收成「步骤2 / 可修改」。细则：[stepper-bar-lessons.md](stepper-bar-lessons.md)。
3. 新组件先问：切了状态，数字和标题还会不会错。会错就把它们做成属性。
4. 条里的每一步必须是项实例（菱形）。套 Frame 的「编组」切不了，也不要发明原稿没有的进度色。
5. 步骤条全家都要自适应。只把条改成 FILL、项还写死 144，拉宽一样空右边。
6. 申请步骤条按 **步骤1 / 2 / 3** 切当前步，再用 **查看修改 有/无** 切整条气泡；步骤3 有查看修改时第 2 步也要有气泡。不要让人删掉某一步。

同法拆完的其余条（理赔这份）：TimelineItem / ProgressStepper 步骤1–4当前 / ProcessStepItem / GuideStepItem（三角 clone，不是 `›`）/ NoticeItem。规格见 `docs/specs/07-stepper.md`。自适应见 [adaptive-stepper.md](adaptive-stepper.md)。
