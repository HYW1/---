# 步骤条：变体、连线、少摊元件（练过的坑）

对照例坐标仍见 [worked-stepper.md](worked-stepper.md)。这里只留**下次直接套**的拆法。换业务时文案/色会换，这些规则不换。

## 1. 变体：当前步 × 整条能力

| 用户在说 | 做成 | 不要 |
|---|---|---|
| 「步骤 1 / 2 / 3 都做」 | 条上 `状态=步骤1` / `步骤2` / `步骤3` | `步骤2` + `步骤2-可修改` 这种假轴 |
| 「有的时候整条有查看修改，有的时候没有」 | 条上第二轴 `查看修改=有/无` | 每一步再做一个气泡元件；用 BOOLEAN 硬藏导致高度不对 |
| 「到步骤三了步骤二为啥没有」 | `有` 时：**每一个已完成步**都出气泡 | 只给第 1 步做气泡，后面完成步漏掉 |
| 「步骤一没有查看修改」 | 步骤1 没有已完成步 → 即使 `有` 也不出气泡 | 步骤1 硬插一颗胶囊 |
| 「删除有问题」 | 每个变体里步数固定，切 `状态` | 让人从实例里删掉某一步；条根上叠一堆 Absolute 线删不干净 |

第二轴是**整条**的能力，不是某一步的私有装饰。有气泡时 padTop 给胶囊留空；无气泡用矮 pad（两份原稿分别 dump）。

矩阵先写全再画。`步骤1 × 有` 和 `步骤1 × 无` 可以长得一样，轴仍要在，右栏才能稳定切。

## 2. 元件：嵌已有项，不要再摊

用户说「不用做元件，直接在这条上做组件」「元件太多」时：

- **不要**再做线组件、气泡组件、半截进度组件。
- **可以**嵌已经存在的点 / 项实例；目录里不必再给原子单独占一张卡。
- 连线、气泡都画在**条变体内部**。

步与步之间用 `[项 HUG][间距 FILL][项]`，不要靠 Absolute 矢量当结构。

## 3. 连线：接到圆边，不要穿过圆心

原稿线是 **0 高 VECTOR/LINE + stroke**（常见 4px、`SQUARE` cap），不是 4px 填充矩形。

圆心对不齐、线穿进勾/数字，通常是这三件事叠在一起：

1. **项比圆宽**（标题 144、圆 85 居中）→ 间距只填项与项之间，线到不了圆边。
2. 用负 x 把线探进上一列 → Auto Layout **后画的间距盖在上一列内圆上**，看起来「线从圆心穿过去」。
3. 透明光晕里露出线，也像穿模。

正确拆法（仍不是新元件）：

- **间距里**：一段 LINE，`x=0`，宽 = 间距，`STRETCH`，竖直对齐圆心。禁止负 x overflow。
- **项上**：左右 stub LINE，`insertChild(0)` 压在点下面，从项边接到圆的可见边。未到若是小圆，stub 长度跟小圆走。
- 第一条藏左 stub、最后一条藏右 stub：BOOLEAN 绑在**项的主组件**上，实例 `setProperties`。不要对实例子层 `LINE.visible =`。
- 颜色在实例上改 `children.find` 到的 stub / 间距线描边：已走空白，未到用底色描边。

验收：线停在内圆外侧；勾和数字上面没有一条线。

## 4. 目录：两轴就摆成网格

- 组件集 `layoutWrap = WRAP`，一行放满第一轴（步骤1/2/3），下一行换第二轴（有/无）。
- 状态标签分行，文案对得上变体值（`查看修改 = 有` 下面三个「步骤1/2/3」）。
- 卡变高后：若规范页 **不是** Auto Layout，后面的 Section 要自己加 `y`，并加高整页，否则会压住时间线。
- 项在目录里单独预览时，左右连线 BOOLEAN 关掉，避免线头露在项外。

## 5. 用户原话对照（防再收错）

| 原话 | 含义 |
|---|---|
| 变体做清楚点，步骤123都做 | `状态` 三值，不是两个「步骤2」 |
| 步骤一没有查看修改，到步骤二才有 | 已完成才出气泡 |
| 到步骤三了步骤二为啥没有 | 所有已完成步都要有 |
| 有查看修改也得做变体，有时整条没有 | 第二轴 `有/无` |
| 线布局不对、样式也有问题 | 描边接到圆边，不要穿心、不要用填色条冒充线 |
| 不用做元件，直接在这里做组件 | 改条，禁止再摊线/气泡原子 |
| 删除有问题 | 步数锁在变体里 |
