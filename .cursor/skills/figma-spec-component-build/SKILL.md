# 规范页组件怎么做

在 `理赔侧设计规范`（`NiXwro23h7CvvWT7GOb1ep`）上，从**参考原稿**做成目录组件。  
Token / 750 / 禁手绘主按钮：先走 `alipay-app-design-system`。乱码稿：先走 `claims-visual-guard`。  
API 语法：`figma-use` + `figma-generate-library`。本 skill 管**怎么拆、怎么变体、怎么对照原稿**。

出稿顺序：`alipay-app-design-system` → **本 skill** → `figma-use` / `figma-generate-library`。

---

## 0. 先锁矩阵，再动手

任何新切片（选择器、表单行、步骤条、图标…）写 Figma 之前，先交一张表，用户没反对再画：

| 组件名 | 变体轴 | TEXT / BOOLEAN | 溯源 node | 为何是变体不是烤死 |
|---|---|---|---|---|
| 域/中文 English | `状态=` … | 标题、序号… | `123:456` | 原稿里能看见的切换 |

**能做成变体的，就做成变体。** 不要只摆一张静态全家福。设计师要在右栏切，点的必须是**实例（菱形）**。

---

## 1. 铁律（都是踩过的坑）

1. **原稿图层是视觉真源。** `use_figma` 量 x/y/w/h/fill/stroke/font，再 `get_screenshot` 对照。禁止用截图模型估 px，禁止「看起来差不多就算了」。
2. **两份原稿先当两份。** 不要合并成「同一条 + 一个胶囊」。申请步骤 步骤2 vs 步骤2-可修改：整列 y 不同，气泡在 `(160,24)`，不是第 1 列里居中撑开的 chip。
3. **状态只换皮，不换料。** `状态=当前` 不要写死「2」，`状态=未到` 不要写死「3」。文案、序号用 TEXT 属性；切 当前→未到 仍是「填写就医情况 / 2」。
4. **点得着才能切。** 目录上的可切对象必须是 COMPONENT / INSTANCE。套一层名叫「点槽」的 Frame，右栏没有变体。
5. **结构 Auto Layout，装饰 Absolute。** 行列、间距、标题用 AL；光晕、连线、徽章、气泡用 Absolute。等分 FILL，拉开 SPACE_BETWEEN，原稿空隙用 spacer 量死，禁止拿 FILL 硬撑。
6. **`resize()` 会缩放子层。** 未到是 **60 圆居中在 85 槽**，不要把 60 的组 `resize(85,85)` 搞出巨大光晕。改外框用 `resizeWithoutConstraints`，圆自己 `resize(60,60)` 再设 x/y。
7. **产品能看见的细节要还原，Sketch 垃圾不要。** 2→3 半截白线（`x=375.5` 宽 `129.5`）是原稿，必须在。穿到圆心的叠线（`w=258.9`）会在透明槽里漏残段，几何等价重画，停在圆的可见边缘。
8. **用户指着原稿说「有」，就加回去。** 不要解释「我帮你整理了」。吃不准就：**默认还原 + 再做一条变体**让他切。
9. **一屏对照再宣布完成。** 组件截图和溯源节点截图并排。差 2px 的对齐、半截线、气泡位置，以原稿为准。
10. **一次 `use_figma` 只做一件可验证的事。** 失败脚本整段不执行。改完立刻截图。颜色 0–1。每调用一次 `setCurrentPageAsync`。禁止 `figma.notify` / `console.log`。

细节与 API 陷阱：[references/plugin-api-traps.md](references/plugin-api-traps.md)。步骤条对照：[references/worked-stepper.md](references/worked-stepper.md)。

## 2. 变体 / 属性 / 变量 怎么拆

### 2.1 变体轴（VARIANT）

原稿里**同一组件、不同样子**，就做轴，优先统一叫 **`状态`**：

| 类型 | 示例 | 做成 |
|---|---|---|
| 流程位置 | 已完成 / 当前 / 未到 | `状态` |
| 表单回填 | 空态 / 回填 / 回填-多个 | `状态` |
| 选中 | 选中 / 未选 | `状态` |
| 整段布局差 | 步骤2 / 步骤2-可修改（整列下移 + 气泡） | `状态` |
| 互相独立的第二视觉 | 2→3 半段白 vs 整段底 | **第二轴** `2到3`，不要揉进 `状态` |

第二轴默认值 = 原稿。目录里若放不下，**隐藏非默认变体**（`visible=false`），实例右栏仍可切。

**不要发明原稿没有的态。** 流程条四步无色差 → 只留 `状态=默认`。加急只改徽章，不要凭空做红点原子。

### 2.2 组件属性（TEXT / BOOLEAN / INSTANCE_SWAP）

| 用 | 不用变体烤死 |
|---|---|
| TEXT `标题` `序号` `标签` | 每个状态下写死不同数字/文案 |
| BOOLEAN 显示气泡 / 显示箭头 | 仅当显隐不改变整列结构；会改变 pad/高度 → 用 `状态` |
| INSTANCE_SWAP / 暴露子实例 | 步骤条里三步都应是 **暴露的 AppStepItem 实例** |

绑定 TEXT 只能写在 **变体主组件** 的图层上，不能写在实例子层的 `componentPropertyReferences`。  
一套 TEXT 属性只有 **一个 defaultValue**：在「当前」主组件改成「3」，「未到」主组件也会变成「3」。目录预览用 **实例 `setProperties`** 写 1/2/3；主组件集可隐藏。

`isExposedInstance = true` 必须在实例 **已经进到父组件里之后** 再设。

### 2.3 Figma 变量（Variables）

颜色 / 字号 / 间距能对上 APP token 的，绑变量，**不要第二套蓝**。

- Brand / 描边 / 字：`#1677FF`
- 新建 variable 必须设 **scopes**（禁止 `ALL_SCOPES`）
- 对不上 token 的原稿一次性色（如步骤条 `#6CA0FF` 底线、`#4492FF` 光晕）先按原稿写死，并在 `docs/specs` 记一笔，不要假装成 Brand

## 3. 搭建顺序（原子 → 项 → 条）

对每个可复用块：

1. **原子**（点、芯片、勾）：只要视觉态，数字若要随父级变，内层数字透明度 0，父级用 Absolute TEXT 绑定 `序号`。
2. **项**（点 + 标题）：嵌原子实例，切 `状态` 只换点；`标题`/`序号` 在项上。
3. **条 / 面板**（多项组成）：AL 排项；连线/气泡 Absolute 且 **z 在点下面**（先 insert 线，再排项）。
4. **目录卡**：跟选择器同一套——Header 64 + 说明 → Section 宽 **2984**、间距 **80**。组件集横向；`状态` 标签格宽 = 变体宽，gap / 左 pad 与组件集一致。
5. **文档**：`docs/specs/NN-xxx.md` 写清：右栏能切什么、不会跟着变什么、溯源 ID、和另一态的肉眼差别。

命名：`域/中文 EnglishName`，变体图层名 `状态=当前` 或 `状态=步骤2, 2到3=半段白`。

## 4. 做「其他」规范切片时

选择器、表单行、日期、城市、图标、按钮…同一套方法，只换溯源：

1. 在规范页找到分区 + **参考原稿** 里的产品 UI 节点（记下 ID）。
2. 用 Plugin API dump 每个状态一份，**不要假设和已做组件同构**。
3. 锁矩阵：凡原稿有空态/选中/禁用/回填/当前，就做 `状态`。
4. 能复用已有原子就复用（`选择器/选项` 进表单行；`AppStepDot` 进 `AppStepItem`），禁止再画一颗一模一样的圆。
5. 跳转 vs 行内（表单行）、等分 FILL（筛选 2/3 列）、滚轮选中带——都是选择器已验证的分布规则，抄规则不抄错节点。
6. 对照截图；用户说某一笔线/一个间距不对，量那一笔，改那一笔。

画布：**750 @2x 原值**，Figma 里不要 ÷2。中文 PingFang SC；行高默认 AUTO。

## 5. 验收

- [ ] 点组件实例（菱形），右栏能切每一个锁过的轴
- [ ] 切 `状态` 后 TEXT 属性还在
- [ ] 嵌套项是暴露实例，不是 Frame
- [ ] 组件截图 vs 溯源截图：线、圆大小、气泡坐标、字重一致
- [ ] 透明槽里没有穿出的残段
- [ ] 目录标签和变体一一对应；共享 TEXT 默认值的主组件若数字错了，已隐藏，预览走实例
- [ ] `docs/specs` 已写切法和溯源，没有把「整理掉的原稿细节」写成规范

---

## 6. 禁止

- 用 Frame 冒充分状态组件
- 把两份原稿收成一种「更干净」的设计
- `resize` 组件来「放大未到圆」
- 在实例子层绑 TEXT 属性
- 为目录好看发明原稿没有的态
- 整组 clone Sketch 叠线当进度条
- 宣布完成却没并排截过原稿
