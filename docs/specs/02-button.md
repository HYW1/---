## 按钮组合组件（自动布局）

底栏 750 白底 + 顶部分割线 #EEEEEE，说明到按钮间距 16。

| 组合 | 使用场景 |
|---|---|
| 吸底 · 带协议：☐ 阅读并同意《好健康平台服务协议》+ 主要操作（686×98 圆角100） | 申请发起页底栏：勾选协议后才能提交，主按钮 + 协议勾选行（750 底栏） |
| 吸底 · 带说明：主要操作（702×102 渐变 圆角49）+ 具体理赔结果…（24 #999） | 提交前需告知的合规说明 + 渐变主按钮，说明在按钮上方（750 底栏） |
| 弹窗 · 带说明：主要操作（686×88 圆角100）+ 后续如何找到我…（24 #999） | 弹窗确认后引导回搜，主按钮 + 说明文字在按钮下 |
| 弹窗 · 带说明 + 文字链：智能诊断结果…（24 #999）+ 主要操作（686×98）+ 诊断有误，忽略（28 #1677FF） | 智能诊断弹窗：说明 + 主按钮 + 诊断有误忽略文字链 |
| 成对 + 文字链：次要操作（337×96 白底描边）+ 主要操作（339×98 #1677FF）+ 取消申请（26 #1677FF） | 申请步骤吸底：次要操作（暂存）+ 主要操作（提交）+ 取消申请文字链（750 底栏） |
