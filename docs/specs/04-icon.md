## 规则

- 功能图标沿用基础库 48×48；规范板展示为 64×64。
- 状态图标源尺寸 128×128；规范板展示为 96×96。
- 业务图标按原稿比例缩放，不拉伸、不改造图形。
- 白色图标需要深色承载底，确保可见。
- 不纳入系统状态栏、电池、Wi-Fi、Home Indicator。
- 不纳入查查专用、乱码、纯装饰和整页图层。
