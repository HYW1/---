## Color

按使用场景分组，已剔除查查工具蓝（#40B0F8 / #0080FF / #00AAFF 等）和出现极少的中性变体。

### 文字灰阶

| 色值 | 用途 |
|---|---|
| #333333 | 主文字（标题 / 正文 / 列表主文案） |
| #555555 | 次文字 |
| #666666 | 辅助文字 |
| #999999 | 占位 / 时间 / 禁用态 |
| #1A1A1A | 强调黑 |
| #000000 | 纯黑 |
