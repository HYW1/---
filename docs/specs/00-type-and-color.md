## Color

按历史稿实际使用场景分类。查查工具色（#40B0F8 Tag、#934300 医院评级）已剔除。

### 文字灰阶

| 色值 | 用途 |
|---|---|
| #333333 | 主文字（标题 / 正文 / 列表主文案） |
| #555555 | 次文字 |
| #666666 | 辅助文字（家人信息 / 辅助正文） |
| #999999 | 占位 / 时间 / 禁用态 |
| #1A1A1A | 强调黑（模块标题：申请理赔怎么做 / 能赔多少钱） |
| #000000 | 纯黑 |

### 品牌蓝 · 操作与链接

| 色值 | 用途 |
|---|---|
| #1677FF | 主操作蓝：去申请 / 去查看 / 选中 chip（26 / 24 字号） |
| #0080FF | 链接蓝：查看详情 / 查看全部 / 了解更多 / 可理赔医院查询（28 字号） |

### 状态标签蓝

| 色值 | 用途 |
|---|---|
| #0073FF | 结论标题蓝：可赔结论大标题（本次就医可以申请理赔，44 字号） |
| #0091FF | 处理中标签：申请中 / 审核中 / 查勘中 / 定损中 / 已结案（26 字号） |
