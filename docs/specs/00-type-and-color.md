# Foundation: Type and color

理赔设计规范 · 视觉基础。适用于理赔报案与理赔向导全链路。字号、字重、字色以 **750 二倍图产品 UI** 为准。

**证据规则：** 只认产品 Frame 内可编辑文本。画布上的流程标注条（宽幅「操作/按钮」、个性化卡片说明、金额=0 等）**不是规范**，不得写入字号表。

## Font usage

中文主体用 PingFang SC（苹方），金融数字用 Alibaba Sans 102 Ver2。字重按场景选，不要混用字体家族。

### PingFang SC（苹方）

中文主体字体。iOS / 支付宝系 C 端默认中文字体。

- Regular · 正文 / 说明 / 辅助 / 时间 / 占位（28 / 26 / 24 / 22）
- Medium · 入口标题 / 模块标题 / 部分操作（36 / 30 / 26）
- Semibold · 工具大标题 / 结论 / 卡片标题 / 按钮 / 链接（56 / 44 / 40 / 36 / 32 / 28 / 26）
- 不用 · 金额数字不要用苹方

### Alibaba Sans 102 Ver2

金融数字字体。支付宝系金额 / 数字强调专用。

- Bold · 获赔金额等数字强调（常见 **44**；亦有 56 / 40 / 28）
- Regular / Medium · 步骤序号、部分金额（32 / 30 / 28）
- 不用 · 中文标题 / 正文不要用此字体

### 蚂蚁保品牌字体

品牌 slogan / 营销标题专用。非正文与列表字体。产品 UI 不以品牌字作为字号 token。
