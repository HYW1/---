# Foundation: Type and color

理赔设计规范 · 视觉基础。适用于理赔报案与理赔向导全链路。字号、字重、字色以 750 二倍图原值为准。

Figma：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=75-2  
页面：`---视觉规范---`（`20:1012`）· 画板 `字体与颜色`（`75:2`）

## Font usage

中文主体用 PingFang SC（苹方），金融数字用 Alibaba Sans 102 Ver2。字重按场景选，不要混用字体家族。

### PingFang SC（苹方）

中文主体字体。iOS / 支付宝系 C 端默认中文字体。

- Regular · 正文 / 说明 / 辅助 / 时间 / 占位（30 / 28 / 26 / 24 / 22）
- Semibold · 标题 / 卡片标题 / 列表强调 / 按钮文字（56 / 44 / 40 / 36 / 32 / 28 / 26）。历史稿最高频标题字重
- Medium · 封面 / 氛围大标题 / 模块大标题 / 状态标题（64 / 48）
- 不用 · 金额数字不要用苹方

### Alibaba Sans 102 Ver2

金融数字字体。支付宝系金额 / 数字强调专用。

- Bold · 金额 / 序号 / 赔付比例 / 获赔金额（历史稿用 Bold，28 / 32 / 36）
- Medium · 基础库默认字重（字号 ≥ 28 的数字强调，如红包 / 折扣 / 额度）
- 不用 · 中文标题 / 正文不要用此字体

### 蚂蚁保品牌字体

品牌 slogan / 营销标题专用。非正文与列表字体。

设计原则：
- 内方外圆 — 科技内核 / 包容守护
- 36° 向阳 — 积极温暖
- 科技链接 — 连接保险与用户
- 1/6 圆角 — 标准化生产

字重 / 样式：
- 通用 — 品牌 slogan、核心信息
- 加粗 — 高级标题、强调
- 倾斜 6° — 辅助场景

字距：1/6 字宽（可按字形微调）

实操参数：
- 倒圆角：8px / 4px / 1px，内角不倒角
- 描边：加粗 1，居中
- 倾斜：6°
