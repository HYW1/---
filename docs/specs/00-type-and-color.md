## Type（PingFang SC）

字重实际用到 Regular / Semibold / Medium 三种（Semibold 高频，不是只有 Medium）。正文主力是 26，不是 28。

| 字号 | 字重 | 字色 | 使用场景 |
|---|---|---|---|
| 64 | Medium | #333333 | 封面 / 氛围大标题，少用 |
| 56 | Semibold | #333333 | 页面大标题 |
| 48 | Medium | #333333 | 模块大标题 / 结果页主标题 |
| 44 | Semibold | #333333 | 页面标题 |
| 40 | Semibold | #333333 | 状态标题 / 结果页主标题 |
| 36 | Semibold | #333333 | 一级模块卡标题 |
| 32 | Semibold | #333333 | 二级标题 / 列表主文案 |
| 30 | Regular | #333333 | 正文 / 说明 |
| 28 | Semibold | #333333 | 按钮 / 卡片标题 / 强调 |
| 28 | Regular | #333333 | 正文 / 列表主文案 |
| 26 | Regular | #333333 | 正文主力 / 列表次行 / 说明 |
| 26 | Semibold | #333333 | 列表主文案强调 / 标签 |
| 24 | Regular | #999999 | 时间 / 辅助说明 / 占位 |
| 22 | Regular | #1677FF | 链接 / 次级动作 |
| 20 | Regular | #FF3B30 | 标签 / 状态小字 |
| 32 | Bold · Alibaba Sans 102 Ver2 | #FF3B30 | 序号 / 步骤数字 |
| 28 | Bold · Alibaba Sans 102 Ver2 | #FF3B30 | 金额 |

## Color

按历史稿实际使用色值，不套支付宝 APP 基础库 token。

| 色值 | 用途 |
|---|---|
| #333333 | 主文字（标题、正文、列表主文案）。历史稿最高频 |
| #555555 | 次文字 |
| #666666 | 次文字 / 辅助正文 |
| #999999 | 时间、占位、辅助说明、禁用态 |
| #1A1A1A | 强调黑，极少 |
| #FFFFFF | 反白（深底 / 主按钮字色） |
| #1677FF | 品牌蓝：主按钮、文字链、选中态、进度。申请链路统一用这个 |
| #40B0F8 | 查查蓝：查查工具 Tag / 查询标签。不要混进申请链路 |
| #0C52B5 | 深蓝：深蓝标题 / 品牌深色辅助 |
| #142C4E | 深蓝：深蓝文字 / 特殊标题 |
| #FF3B30 | 警示红：拒赔、警告、金额、状态失败。不要整页铺红 |
| #FF6430 | 提示橙：待补齐、需处理。短状态用 |
