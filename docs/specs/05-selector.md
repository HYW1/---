# Selector

理赔设计规范 · 选择器。历史稿 / 业务流程原样贴图，750 二倍图原值。

独立画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=192-3108  
页面：`---视觉规范---`（`20:1012`）· 画板 `选择器`（`192:3108`）

## 表单行选择

| 场景 | 来源 |
|---|---|
| 申请表单 · 空态请选择 | 历史稿表单页 |
| 申请表单 · 已选回填 | 业务流程申请步骤（含多选标签回填） |
| 申请表单 · 必填选择行 | 历史稿表单页 |

覆盖：事故类型行内二选一、就医类型 / 就诊医院 / 就诊时间 / 疾病名称「请选择 ›」、已选标签回填。

| 场景 | 来源 |

## 选择行

- 事故类型 / 就医类型 / 就诊医院 / 就诊时间 / 疾病名称（原图层）
- 复诊确认 · 是/否
- 选项按钮 · 默认 / 选中 / 错误（与按钮规范同一标本）

## 规则摘要

- 必填 `*` `#FF3B30`
- 空态「请选择」`#999` + ›；已选值 `#333`
- 多选回填为可移除蓝标签；点行进入面板
- 医院搜索命中词与等级 Tag 用 `#1677FF`
