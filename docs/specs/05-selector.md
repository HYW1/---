# Selector

理赔设计规范 · 选择器组件。从历史稿 / 业务流程提取 **面板与行级** 组件（非整页场景）。

独立画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=192-3108  
主件：画板右侧 `选择器 Components（主件）`

## 提取原则

- 只收录可复用的面板 / 行 / 原子件（BottomSheet、浮层、搜索框、列表项、表单行、选项）
- 不含状态栏、整页背景、键盘、背后页面
- 疾病浮层取历史稿 `Frame 242` 面板本体，去掉底栏 CTA
