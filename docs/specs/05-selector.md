# Selector

理赔设计规范 · 选择器。收录 **展开面板、原子件、触发行**；不收录整页场景。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23970

## 规范原则

1. **原子化分层**：基础元素 → 组合模块 → 完整组件  
2. **三段式命名**：`选择器/{层级·功能} English` + 属性 `状态=`（对齐现有 SheetHeader）  
3. **状态穷举**：默认 / 选中 / 禁用（及必要业务态），Component Properties 一键切换  
4. **响应式断点**：Variables 集合 `Selector` · 模式 `Mobile` / `Pad`；Auto Layout，间距绑变量  
5. **活文档**：画板内嵌原则说明 + 更新日志；已有「选医院 / 表单理赔申请」不改动  

一句话：规范 = 原子分层 × 统一命名 × 状态预设 × 响应逻辑 × 可追溯文档。

## 收什么 / 不收什么

| 内容 | 结论 | 理由 |
|---|---|---|
| 已有 HospitalSelector / 表单触发行 / 事故类型 | **收（已有·勿改）** | 用户已建规范 |
| 已有 SheetHeader / SearchBar / SectionTitle / HospitalItem / GradeBadge | **收（已有·勿改）** | 面板原子 |
| 规范补齐 · L0/L1/L2（疾病/对象/日期/确认） | **收** | 历史稿缺口，按原则重建 |
| 整页申请表、状态栏、键盘、背后页面 | **不收** | 场景页 |

## 提取原则

1. 只抽面板与行级，不贴完整手机页  
2. 回填只给规范态：**一个 / 多个 / 时间**，不做字段枚举  
3. 组合以上层实例引用下层，禁止拆改已有规范组件  
4. 间距 / 色 / 圆角绑 `Selector` Variables；Pad 模式放大间距与面板宽
