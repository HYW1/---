# Selector

理赔设计规范 · 选择器。收录 **展开面板、原子件、触发行**；不收录整页场景。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23970

## 收什么 / 不收什么

| 内容 | 结论 | 理由 |
|---|---|---|
| `HospitalSelector` 展开面板（搜索结果 / 历史热搜） | **收** | 选择器展开态本体 |
| `SheetHeader` / `SearchBar` / `SectionTitle` | **收** | 面板结构件 |
| `SearchPill` / `HospitalItem` / `GradeBadge` | **收** | 面板内候选项与结果行 |
| `SelectionConfirm` 选中确认条 | **收** | 多选底部确认 |
| `DiseaseSelector` 疾病多选面板 | **收** | 搜索框 + 推荐标签 |
| `PersonCard` 对象卡 | **收** | 「为谁查」选中/未选 |
| `DatePicker` 日期滚轮 | **收** | 年/月/日面板 |
| 表单行空态「请选择」 | **收** | 触发行 |
| 行内二选一（事故类型） | **收** | 行内选择器 |
| 回填 · 一个 / 多个 / 时间 | **收** | 选完后：标签一个、标签多个、时间纯文本 |
| 整页申请表、状态栏、键盘、背后页面 | **不收** | 场景页 |

## 结构

### 选医院（展开态 + 原子件）

| 组件 | 变体 |
|---|---|
| 选择器/就诊医院 HospitalSelector | 搜索结果 · 历史热搜 |
| 选择器/弹层标题 SheetHeader | 默认 |
| 选择器/搜索栏 SearchBar | 默认 · 激活 |
| 选择器/分组标题 SectionTitle | 默认 |
| 选择器/搜索标签 SearchPill | 单标签（历史稿 HospitalPill） |
| 选择器/医院列表项 HospitalItem | 标准 · 长文案 |
| 选择器/等级徽章 GradeBadge | 默认 |
| 选择器/选中确认条 SelectionConfirm | 数量=一个 · 多个 |

### 选疾病 / 对象 / 日期（历史稿补齐）

| 组件 | 变体 | 来源 |
|---|---|---|
| 选择器/疾病 DiseaseSelector | 回填=空 · 一个 · 多个 | 历史稿「添加疾病」 |
| 选择器/对象卡 PersonCard | 选中=是 · 否 | 历史稿「为谁查」 |
| 选择器/日期 DatePicker | 默认 | 历史稿滚轮面板 |

### 触发行

| 组件 | 说明 |
|---|---|
| 选择器/表单行/空态-请选择 | 空态 |
| 选择器/表单行/空态-就诊时间 | 空态 |
| 选择器/行内二选一/事故类型 | 行内二选一；变体 `选中=疾病/意外`，选项用 FilterChip 已选/未选 |
| 选择器/表单行/回填-标签-一个 | 标签回填 · 一个 |
| 选择器/表单行/回填-标签-多个 | 标签回填 · 多个 |
| 选择器/表单行/回填-文本-时间 | 时间纯文本回填 |

## 提取原则

1. 只抽面板与行级，不贴完整手机页  
2. 回填只给规范态：**一个 / 多个 / 时间**，不做字段枚举  
3. 原子件从面板拆出，便于复用  
4. 触发行做成 Auto Layout，但**不改**颜色、箭头、字体等原样式节点  
5. **已有选择器组件规范不改动**；缺口从历史稿另开分区补齐
