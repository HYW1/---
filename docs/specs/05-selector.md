# Selector · 就诊医院

理赔设计规范 · **就诊医院选择器**。按「元件 → 组合 → 组件」分类排布。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23854

## 原则

1. **原子分层**：元件 → 组合 → 组件  
2. **三段式命名**：`选择器/就诊医院/{功能}` + `状态=`  
3. **状态穷举**：Component Properties 切换  
4. **Variables**：`Selector` · Mobile / Pad  
5. **活文档**：画板内更新日志；**表单理赔申请不改动**；HospitalSelector 本体结构保持
