# Selector · 选择器

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23970

按选择器规范分层：**选项标签 → 选项组 → 表单行 → 选择面板 → 确认条**。

字体统一 **PingFang SC（苹方）**；正文 Regular，强调 Medium/Semibold。行高默认 AUTO（搜索占位 26/40 除外），避免自定义 PIXEL 行高撑乱对齐。

## 1. 选项标签 FilterChip

原子选项，供选项组 / 行内选择复用。

| 组件 | 属性 |
|---|---|
| 选择器/选项 | 状态=选中 · 未选 |

## 2. 选项组 OptionGroup

选项标签的行列编排。

| 组件 | 属性 |
|---|---|
| 选择/选项组 OptionGroup | 行数 · 列数 · 选项样式（一行字 / 两行字） |

## 3. 表单行 FormRow（触发器）

进入选择的入口，分跳转型与行内型。

| 组件 | 类型 | 属性 |
|---|---|---|
| 选择器/表单行/就诊医院 | 跳转选择 | 状态=空态 · 回填-一个 · 回填-多个 |
| 选择器/表单行/就诊时间 | 跳转选择 | 状态=空态 · 回填 |
| 选择器/表单行/事故类型 | 行内选择 | 状态=疾病 · 意外 |

- 跳转选择：右侧文案/标签 + 箭头，打开选择面板
- 行内选择：右侧直接放选项组，无需弹层

### 4.2 查查选择器

对照历史稿与截图重做；不单独拆元件，标签复用 `选择器/选项`。

| 组件 | 属性 | 结构 |
|---|---|---|
| 选择器/药品查查 MedicineLookup | 状态=疾病面板 | 搜索栏 + 筛选等分按钮行（3 等分 FILL，灰底胶囊）+ 选项标签网格 |
| 选择器/医院查查 HospitalLookup | 状态=城市级联 | 搜索栏 + 筛选等分按钮行（2 等分 FILL，灰底胶囊）+ 省市级联通栏 |

对照历史稿 `医院查查2备份 5`（750）：

- 画板宽 **750**；搜索/筛选内容区左右 **48**（内容宽 **654**）
- 搜索：高 64、圆角 32、底 `#EBEFF5`，占位 26 / lh 40
- 筛选行：独立等分按钮，高 64、圆角 32、底 `#EBEFF5`、gap **16**
  - 医院：2×**319**；药品：3×**207**
  - 打开态：蓝字 Medium + 实心三角 17×10（圆角 1）；关闭态：同一路径旋转 180°（底色不变）
- 级联：**通栏 750**；侧栏宽 **286**、底 `#F5F5F5`、行高 **88**；选中行白底 + 左侧蓝条 **4×24** r4；选中项下方第一块灰底 **右上倒圆角 24**；侧栏文案左对齐；右列选中蓝字
