## 规则摘要

- 必填 `*` 为 `#FF3B30`，紧跟 Label
- 空态右侧「请选择」`#999999`；已选值 `#333333`
- 右箭头 › 为进入面板 / 日期选择的示意
- 多选回填用可移除蓝标签；点行仍进入选择面板
- 医院等级 Tag 用理赔链接蓝 `#1677FF`，不用查查专用色
