# Selector

理赔设计规范 · 选择器。收录 **展开面板、原子件、触发行**；不收录整页场景。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23970

## 收什么 / 不收什么

| 内容 | 结论 | 理由 |
|---|---|---|
| `HospitalSelector` 展开面板（搜索结果 / 历史热搜） | **收** | 选择器展开态本体 |
| `SheetHeader` 弹层标题 | **收** | 面板结构件 |
| `SearchBar` 搜索栏 | **收** | 面板内筛选 |
| `SectionTitle` 分组标题 | **收** | 面板内分区 |
| `SearchPill` 历史/热搜标签 | **收** | 面板内候选项 |
| `HospitalItem` 医院列表项 | **收** | 面板内结果行 |
| `GradeBadge` 等级徽章 | **收** | `HospitalItem` 组成件 |
| 表单行「请选择」（就诊医院 / 就诊时间） | **收** | 选择器收起态 / 触发行 |
| 行内二选一（事故类型） | **收** | 行内选择器 |
| 整页申请表、状态栏、键盘、背后页面 | **不收** | 场景页，不是选择器组件 |

## 结构

### 选医院（展开态 + 原子件）

| 组件 | 变体 |
|---|---|
| 选择器/就诊医院 HospitalSelector | 搜索结果 · 历史热搜 |
| 选择器/弹层标题 SheetHeader | 默认 |
| 选择器/搜索栏 SearchBar | 默认 · 激活 |
| 选择器/分组标题 SectionTitle | 默认 |
| 选择器/搜索标签 SearchPill | 标签组 · 单标签 |
| 选择器/医院列表项 HospitalItem | 标准 · 长文案 |
| 选择器/等级徽章 GradeBadge | 默认 |

### 触发行（收起态）

| 组件 | 说明 |
|---|---|
| 选择器/表单行/空态-请选择 | 就诊医院触发 |
| 选择器/表单行/空态-就诊时间 | 就诊时间触发 |
| 选择器/行内二选一/事故类型 | 疾病 / 意外 |

## 提取原则

1. 只抽面板与行级，不贴完整手机页  
2. 展开态与触发行成对出现  
3. 原子件从面板拆出，便于复用与标注
