APP 真源：https://www.figma.com/design/4Q2KGg9fstrN2BWCwYChzi/?node-id=6195-1074

## APP 选择类（贴图）

| 组件 | 说明 |
|---|---|
| 选择/勾选框 Checkbox | 选中 / 未选中 / 不可编辑 |
| 选择/开关 Switch | 开 / 关 / 不可编辑 |
| 选择/筛选标签 FilterChip | 1 行 / 2 行 · 选中 / 未选中 |
| 选择/选项组 OptionGroup | 2/3/4 列 · 一行字 / 两行字 · 多行网格 |

## 表单选择 / 列表选择（贴图）

| 组件 | 说明 |
|---|---|
| 输入/输入表单 InputListItem | Label + 暗提示/内容 + ›（选择触发行） |
| 展示/列表项 ListItem | 箭头 / 开关 / 勾选 / 金额 / 按钮等右槽 |
