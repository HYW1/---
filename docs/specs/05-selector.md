# Selector · 就诊医院

理赔设计规范 · **就诊医院选择器**。按「元件 → 组件」分类排布（无组合层）。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-23854

## 原则

1. **分层**：元件 → 组件（不单开组合层）  
2. **命名**：`选择器/就诊医院/{功能}` + `状态=` / `数量=`  
3. **属性**：文本属性改文案；吸底条 **暴露嵌套** SelectedChip，顶层可改  
4. **自动布局**：元件与新建组件均为 Auto Layout  
5. **Variables**：`Selector` · Mobile / Pad  
6. **活文档**：画板更新日志；表单理赔申请不改

## 不收

- 选疾病 / 组合层 / 勾选符号  
- 整页场景、键盘、状态栏  
- 表单触发行（见「表单理赔申请」，不改）
