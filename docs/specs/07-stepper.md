# Stepper · 步骤条

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=340-5996

排版对齐「选择器」：顶栏 **Header**（64 标题 + 分类说明）→ 分区 Section（宽 2984、间距 80）：

**1. 申请步骤 → 2. 时间线 → 3. 进度 → 4. 流程总览 → 5. 引导与须知 → 6. 参考原稿**

组件按选择器同一套 **分布规则** 做 Auto Layout：

- 等分项用 **FILL**（选项组）；拉开用 **SPACE_BETWEEN**（星期、步骤标题）
- 原稿间距用 **spacer** 量死，不拿 FILL 硬撑
- 重叠装饰（光晕、连线、徽章）用 **Absolute**，矢量从原稿 clone
- 目录卡：组件集横向、`状态` 格宽 = 变体宽、gap/左 pad 与组件集一致

变体属性统一 **`状态=`**。

规范页上的组件集是「全家福」。要换状态，请点 **实例**（菱形），不要点外面的框。

| 组件 | 右栏能切什么 | 不会跟着变 |
|---|---|---|
| 申请步骤项 AppStepItem | `状态` 已完成 / 当前 / 未到 | `标题`、`序号` |
| 申请步骤条 AppStepper | `状态` 步骤2 / 步骤2-可修改；`2到3` 半段白 / 整段底；内部三步已暴露 | 三步标题 |
| 时间线项 TimelineItem | `状态` 已完成 / 进行中 / 待完成；内部点/标已暴露 | `标题` |
| 时间线 TimelineStepper | `状态` 进行中 / 加急中；内部四步已暴露 | 四步标题 |
| 进度点 ProgressDot | `状态` 当前 / 预计 | `序号`、`行1`、`行2`、`副文案` |
| 进度条 ProgressStepper | `状态` 步骤1–4当前；内部四点已暴露 | 四步标题与时长 |
| 流程项 ProcessStepItem | （无状态轴） | `序号`、`标题` |
| 引导项 GuideStepItem | （无状态轴） | `序号`、`副标`、`主标` |
| 须知项 NoticeItem | （无状态轴） | `序号`、`标题`、`说明` |

点条上的一步应选中**项实例**（菱形），不是外框。切状态只换皮，标题和序号还在。

## 状态选用说明

- **需要 `状态` 变体的**：申请步骤点/项/条、时间线点/标/项/条、进度点、进度条（当前步位置）。
- **单态即可的**：流程项/条、引导项/条、须知项/列表（原稿无可切换视觉态；文案走 TEXT）。
- **加急**：只改时间线标文案/色，不要另做红点原子（无产品 UI 证据）。
- **点得着**：条里的每一步必须是项实例。套 Frame 的「编组 / 项」右栏没有变体。
