## 状态选用说明

- **需要 `状态` 变体的**：申请步骤点/条、时间线点/标/条、进度点（当前 vs 预计）。
- **单态即可的**：流程条、引导条、须知列表（原稿无可切换视觉态）。
- **加急**：只改时间线标文案/色，不要另做红点原子（无产品 UI 证据）。
