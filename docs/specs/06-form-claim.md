# FormRow · 表单行（选择器 · 触发器）

归属选择器规范第 3 层，详见 [`05-selector.md`](./05-selector.md)。

画板：https://www.figma.com/design/NiXwro23h7CvvWT7GOb1ep/?node-id=213-24581

## 跳转选择

打开选择面板；右侧为值区 + 箭头。

| 组件 | 状态 |
|---|---|
| 选择器/表单行/就诊医院 | 空态 · 回填-一个 · 回填-多个 |
| 选择器/表单行/就诊时间 | 空态 · 回填 |

- 就诊医院：`Label` · `Value`(Fill) · `ChevronSlot`；多选 Tag 纵向 Auto Layout，箭头对齐首行
- 就诊时间：同上；空态「请选择」，回填日期

## 行内选择

不打开弹层，直接在行内点选。

| 组件 | 状态 |
|---|---|
| 选择器/表单行/事故类型 | 疾病 · 意外 |

- 结构：`Label` + `Options`（`选择器/选项` 芯片 ×2）
