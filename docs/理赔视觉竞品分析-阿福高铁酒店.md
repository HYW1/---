## 一、目的

不是盘点「理赔要哪几类材料页」，而是：

1. 这些产品自己怎么组织功能、怎么排信息、怎么给示例、怎么做进度  
2. 哪些视觉手法以后做理赔界面可以借  
3. 哪些做法看起来花、但对「一次把事情说清」没有帮助

阿福、定高铁、酒店覆盖三种完全不同的产品形态（健康助手 / 出行票务 / 住宿预订）。先按各自产品看，再横比手法，不要先套同一套理赔步骤。

---

## 二、看图时可以想的问题（不是分类标签）

贴图时不要用这些当文件夹名。写观察时可以拿来当检查清单：

| 想什么 | 在界面上具体看 |
| --- | --- |
| 信息清不清 | 3 秒能不能找到标题、关键数字、状态 |
| 示例明不明 | 有没有正误对比、标注、拍什么的示意 |
| 表单好不好填 | 空态、步骤、必填、校验出现的时机 |
| 进度看不看得懂 | 步骤条、百分比、下一步文案 |
| 规则读不读得下去 | 协议/须知是长文还是结构化条目 |

## 三、Figma 怎么分类

`产品-功能模块-界面名`  
例：`阿福-病历夹-上传须知`、`携程-电子票`、`爱彼迎-取消政策`

1. `00-说明与维度`：分类原则  
2. `01-阿福-按产品功能`：首页对话、健康档案、病历夹、就医服务、AI智能相机、AI诊室、饮食记录、健康小目标、家庭健康管理、摔倒守护、量表自测、评价与反馈  
3. `02-定高铁类`：携程 / 航旅纵横 / 飞猪，各按该 App 常见功能留槽  
4. `03-酒店类`：爱彼迎 / 美团，各按该 App 常见功能留槽  
5. `04-跨场景对比墙`：等图齐后，抽「信息层级 / 拍摄示例 / 进度 / 规则」等视觉手法横比  
6. `05-结论与建议`

高铁、酒店的空槽名称只是该 App 里常见功能，有截图后按真实界面改名；没有的功能就空着。

## 四、阿福（已按产品功能贴板）

原图仍在「阿福-原始素材（未分类源）」，分类区是克隆，没有挪走你的源文件。

| 功能模块 | 贴了什么 | 视觉上值得盯的 |
| --- | --- | --- |
| 首页对话 | 健康助手对话、智能体介绍 | 对话入口怎么占屏、介绍卡和图标怎么讲功能 |
| 健康档案 | 仪表盘、基础信息、健康史、就医资料入口 | 仪表盘数字层级；表单分组；资料入口四宫格 |
| 病历夹 | 上传就医资料、四宫格 + 上传须知 + 错误示例 | 正误示例并排，是这套截图里最完整的「教用户怎么拍」 |
| 就医服务 | 服务首页、介绍、详情长页（权益/价格/须知） | 长详情怎么切段；价格和须知的位置 |
| AI智能相机 | 拍皮肤介绍、拍报告/舌苔正误示例 | 取景示意 + 合格/不合格对比 |
| AI诊室 | 进入问诊三步、问询进度 20% | 步骤条和百分比怎么缓解等待 |
| 饮食记录 | 热量计算、空态、拍照识食、已记录 | 空态、相机入口、记录列表密度 |
| 健康小目标 | 选卡、睡眠/饮食/运动/减重问卷、计划确认 | 问卷一题一屏；计划页信息密度 |
| 家庭健康管理 | 添加成员、功能说明 | 说明页图文结构 |
| 摔倒守护 | 介绍 + 协议、开通三步表单 | 协议出现时机；三步表单怎么拆 |
| 量表自测 | 焦虑开始、结果页 | 结果页分数和解读的层级 |
| 评价与反馈 | 截图上传、语音评价正/反 | 反馈里的上传控件；正反评价的视觉差 |

### 从阿福视觉里，以后做理赔可以借的

1. **正误示例并排**（病历夹上传须知、拍报告/舌苔）：比单独一句「请上传清晰照片」有效得多。  
2. **进度可见**（AI 诊室 20%、摔倒守护三步）：把「现在到哪了」做成界面，而不是口头安慰。  
3. **一题一屏问卷**（健康小目标）：复杂采集可以拆步骤，避免一张表把人吓走。  
4. **阿福几乎没有交易凭证页**（订单金额/发票很少）：理赔如果要金额证据，还得看支付或医院凭证，不能从阿福这套功能里直接抄票面。

## 五、定高铁 / 酒店（先按产品功能留槽）

截图还没贴。槽位按各 App 自己的功能，不按理赔六类。

### 5.1 高铁

| 产品 | 功能槽（有什么贴什么） |
| --- | --- |
| 携程 | 搜索购票、车次列表、车次详情、订单详情、电子票、退票改签 |
| 航旅纵横 | 行程首页、航班或车次详情、电子客票、出行动态、延误证明、值机选座 |
| 飞猪 | 搜索购票、车次列表、订单详情、电子票、退改签、发票 |

看这些界面时可以记：时间怎么成为第一视觉、电子票好不好整页截、退改和证明入口在不在详情里。记下手法即可，不要把页面改名叫「理赔-凭证」。

### 5.2 酒店

| 产品 | 功能槽（有什么贴什么） |
| --- | --- |
| 爱彼迎 | 搜索探索、房源详情、预订确认、行程、取消政策、费用明细 |
| 美团 | 搜索列表、酒店详情、订单详情、入住凭证、取消政策、发票 |

看这些界面时可以记：入住人/房型/日期是否同屏、取消政策是色条还是灰字长文、价格能不能展开。同样保持产品原名。

## 七、对理赔视觉的启发（先从阿福抽出，高铁酒店图齐后再补）

| 阿福上看到的手法 | 以后做理赔可以怎么用 |
| --- | --- |
| 上传须知 + 正确/错误示例并排 | 补件/拍照页不要只写要求，把合格长什么样画出来 |
| 问询进度百分比 + 三步条 | 理赔提交后的等待、补件进度做成可见状态 |
| 问卷一题一屏 | 材料采集拆步，降低单屏负担 |
| 健康档案分组表单 | 身份/就诊/费用字段分组，而不是一长串输入框 |
| 缺少订单/发票页 | 理赔金额核对还得从支付或医院凭证找参照，别在阿福功能里硬找 |

高铁、酒店的图贴上之后，把同样格式的「手法 → 可借」补进这张表。不要等到按理赔六类凑齐再写。
