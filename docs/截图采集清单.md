## 命名规则

例：`高铁-携程-订单详情-01`、`酒店-爱彼迎-取消政策-02`

## 页面类型

| 代码 | 含义 | 优先级 |
| --- | --- | --- |
| P1 | 订单/服务详情 | ★★★ 必须 |
| P2 | 凭证/票面/电子单 | ★★★ 必须 |
| P5 | 材料上传/示例指引 | ★★ 强烈建议 |
