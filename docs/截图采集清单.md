# 截图采集清单（按产品功能贴图）

配合文档：`docs/理赔视觉竞品分析-阿福高铁酒店.md`  
Figma：https://www.figma.com/design/u6EHQzZ1BlQZIRvSDDib53/分析

调研目的是看清这些产品自己怎么做视觉，再反哺理赔视觉。  
**分类按该产品自己的功能模块，界面是什么就叫什么，不要按理赔流程拆。**

## 命名规则

`产品-功能模块-界面名`

例：`阿福-病历夹-上传须知`、`携程-电子票`、`爱彼迎-取消政策`

有截图后按真实界面改名，空槽名称只是该 App 里常见功能，不是必须凑齐。

## 看完图怎么写

1. 每个功能模块里挑 1 张最能说明「这个产品视觉怎么做事」的界面  
2. 用文档里的看图卡片写：信息怎么分层、示例怎么给、进度怎么显示  
3. 最后再抽：哪些手法以后做理赔视觉可以借
