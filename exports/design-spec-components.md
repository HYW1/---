# 做视觉规范 + 做组件

把产品 UI 参考原稿做成规范目录里的可切换组件。业务文案、文件、色板会换；拆法不变。不要当成「只做理赔步骤条」。

| 会换 | 不换 |
|---|---|
| 文件、画布、token、文案、溯源节点 | 先锁矩阵、状态与内容分离、Auto Layout 结构 + Absolute 装饰、原稿对照 |

Token / 画布跟当前产品的设计系统走。Figma 里保持设计稿原值；÷2 只给代码逻辑宽。

## When to use

- 做或改视觉规范页、组件目录、选择器、表单、步骤条、导航、列表、弹层
- 从参考原稿（含 Sketch 导入）还原成 Auto Layout 组件
- 加状态变体、TEXT 属性、Figma 变量
- 用户说和原稿不一样、切不了状态、点到的不是组件

不要用本 skill 去做没有原稿的运营海报、写代码、或纯插画质感。

## Instructions

1. 写清文件与页（用户给的 URL，不要写死 fileKey）。
2. 写清画布与 token（该产品的设计系统）。抄本文件已有规范页的 Header / Section / 卡，不要发明新网格。
3. 先搜再画：本地组件 → 已订阅库 → 再新建。有库的按钮、导航、开关禁止手绘。禁止 detach 来「修对齐」。
4. 交出变体矩阵，用户没反对再画：

| 组件名 | 变体轴 | TEXT / BOOLEAN / 变量 | 溯源 node | 为何不烤死 |
|---|---|---|---|---|
| 域/中文 English | 状态=… | 标题、序号… | 123:456 | 原稿里能看见的切换 |

5. 只读 dump 每个溯源节点：x/y/w/h、fills、strokes、strokeWeight、strokeCap、font、effect、layoutPositioning、子树。矢量线看每一条的 x/w，不要只看编组包围盒。
6. 按原子 → 项 → 条/面板 → 目录卡 → 组件 description 搭建。写操作用 use_figma 必须串行；每次最多 setCurrentPageAsync 一次；颜色 0–1；改字前 loadFontAsync；return 所有变更 id。禁止 figma.notify、console.log、编造 node id。
7. 每做一个组件就截图，和溯源并排对照。差 2px、半截线、气泡坐标以原稿为准。
8. 不删、不改参考原稿。规范页末尾保留溯源分区。

## 铁律

1. 原稿图层是视觉真源。禁止用截图模型估 px。
2. 两份原稿先当两份。布局差用变体，不要收成更干净的一种。
3. 状态只换皮，不换料。位置/选中/空态是「状态」；标题、序号、标签是 TEXT。切当前→未到，该步文案和数字还在。
4. 点得着才能切。必须是 COMPONENT / INSTANCE（菱形）。套一层 Frame（点槽、卡壳）右栏没有变体。
5. 结构 Auto Layout，装饰 Absolute。等分 FILL，拉开 SPACE_BETWEEN，原稿空隙用 spacer 量死。光晕、连线、徽章、气泡 Absolute，并且压在内容下面（先 insert 线）。
6. resize() 会缩放子层。小图居中在大热区：外框 resizeWithoutConstraints，内图形自己 resize 再设 x/y。不要把 60 的圆 resize 成 85。
7. 还原产品能看见的；丢掉导入垃圾。半截进度线、错位徽章是稿。穿出透明边的叠线按可见边缘重画，不要整组 clone。
8. 用户指着原稿说「有」，就加回去。不要解释「我帮你整理了」。吃不准：默认还原，再做一条变体让他切。
9. Groups 先改成 Frame + Auto Layout 再做成组件。
10. 热区不够就加大透明槽，不要缩放图形。徽章/气泡可能探出：不要随便开 clip content。Absolute 子节点 constraints 用 MIN/MIN，避免父级拉伸跑位。

## 做规范页

规范页是给设计师扫组件的，不是一张业务稿。

- 结构：标题 →（可选）色/字/间距标本 → 组件 Section（一个家族一块）→ 参考原稿。
- 抄本文件已有规范页的宽和间距。组件本身保持产品画布宽（常见 750），不要把组件拉成目录宽。
- 卡是壳，组件是芯。卡的背景、标题、状态标签不属于组件。不要把目录灰底烤进组件。
- 状态标签文案必须等于变体值；格宽等于变体宽。
- 组件集做全家福。若 TEXT 默认值让所有主组件显示同一个数字，把集藏起来，卡上放预览实例并用 setProperties。切状态请点实例。
- 组件 description 写：右栏切什么、TEXT 改什么、溯源 node id。图层名用「域/中文 English」，禁止「编组-2备份」「Rectangle 123」。

## 变体 / 属性 / 变量

变体：默认轴名「状态」。Size / Type / 平台 / 第二条进度线用第二轴，不要揉进状态。会改高度的装饰用状态，不要只用 BOOLEAN 硬藏。第二轴默认值=原稿；目录放不下就隐藏非默认变体（实例仍可切）。

不要发明原稿没有的态。移动端稿默认不做 hover/press。空/错/加载/禁用有稿才做。轴相乘超过 30 就拆子组件。图标用 INSTANCE_SWAP，不要每个图标一个变体。默认变体=原稿主态。

属性：TEXT 绑在主组件图层，不能绑实例子层。一套 TEXT 只有一个 defaultValue（改「当前」的数字，「未到」也会变）。目录上的 1/2/3 用实例 setProperties。isExposedInstance 必须在实例进入父组件之后再设。BOOLEAN 只用于不改变高度的显隐。

变量：能对上该产品语义 token 的 fill/字号/间距/圆角就绑，并设 scopes，禁止 ALL_SCOPES。对不上的一次性色按原稿写死。间距优先 4/8 刻度；原稿量死的非刻度（如 129.5）以原稿为准，不要取整。

## 搭建顺序

1. 原子（点、芯片、勾）。数字随父级变 → 内层数字透明，父级 Absolute TEXT 绑序号。
2. 项（原子+标题）。嵌原子实例；切状态只换皮。
3. 条/面板。AL 排项；装饰 Absolute 且先插入。
4. 目录卡 + description。
5. 验收并排截图。

## 换场景

- 同一规范页下一刀：同一骨架，新溯源，原子能复用就嵌，禁止再画一颗同款圆。
- 同一设计体系、另一业务：同一 token/画布/库，换文案、字段、溯源。
- 另一 Figma 文件 / 另一产品：换 fileKey、画布、设计系统；拆法照旧。
- 不要假设和已做组件同构。

## 验收

- 点实例，右栏能切锁过的每一轴；改 TEXT 不打乱布局
- 切状态后标题/序号还在
- 组合里的项是暴露实例，不是 Frame；没有 detach
- 组件 vs 溯源：线、尺寸、装饰坐标、字重、描边 cap/align 一致
- 透明热区无穿模；气泡没被 clip 裁掉
- 状态标签与变体值一致；组件未吃进目录卡背景
- 参考原稿还在；description 写了切法与溯源
- 没有把 A 产品的 token/文案抄进 B 产品

## 禁止

- Frame 冒充分状态组件；为对齐 detach
- 把两份原稿收成一种更干净的设计
- 用 resize 放大带装饰的组；在实例子层绑 TEXT
- 为目录发明原稿没有的态；整组 clone 导入叠线
- 没并排截过原稿就宣布完成；删改参考原稿
- 手绘已有库的按钮/导航/开关；移动端稿无端加 hover
- 把量死的 129.5 取整掉

## Examples

- 「把选择器做成规范组件」：锁选中/未选；选项原子复用进选项组和表单行。
- 「步骤条和原稿不一样」：并排截图；dump 每条连线的 x/w；还原看得见的半截白线；穿到圆心的叠线按圆的可见边缘重画。吃不准就默认还原，再加一条「整段底」变体。
- 「点了切不了状态」：点到的是 Frame 不是实例。改成项实例并暴露；数字做成 TEXT 属性，不要烤进状态。
- 「给另一业务做表单行规范」：同一拆法，换 token/文案/溯源。

## Common edge cases

- use_figma 报错 = 整段没执行。读报错再改，不要原样重试。
- 改字前必须按图层当前 fontName loadFontAsync。中文字体跟产品规范（常见 PingFang SC）。
- layoutSizing 是 FIXED|HUG|FILL；轴模式是 FIXED|AUTO。FILL 只能给已在 Auto Layout 父级且非 Absolute 的子节点。
- TEXT 属性加在 COMPONENT_SET 上，不要对单个变体的 componentPropertyDefinitions getter 动手。
- 克隆变体进同一 SET 再改名可加第二轴。
- Sketch 导入常有多条同名线。先看产品看见几段什么颜色，再画 2～3 条等价 VECTOR（抄 cap/weight），停在可见图形边缘。
